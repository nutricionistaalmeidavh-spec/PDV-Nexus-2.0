# Licenciamento e dependências

O código original deste repositório, incluindo servidor, módulos locais, front-end e scripts de compilação próprios, está sob **MIT** (arquivo `LICENSE`). A interface React já usava MIT. Esta licença permite uso, modificação, distribuição e venda, desde que se preservem os avisos de copyright e licença. A marca registrada ArtiSys, quando aplicável, não é licenciada como parte do código.

**O núcleo usa exclusivamente bibliotecas open source e funciona self-hosted por R$ 0**, sem conta em nuvem, API comercial ou assinatura. Componentes adicionais de hardware (driver do fabricante, porta serial ou spooler Windows) dependem do equipamento efetivamente presente e podem possuir termos próprios; não são requisito para o caixa operar.

Cada pacote de terceiros mantém sua licença. Ao distribuir instalador, preserve avisos e licenças das dependências conforme exigido pelos respectivos projetos. As integrações externas pagas devem permanecer opt-in e nunca bloquear funções essenciais.

O repositório não inclui NF-e/NFC-e; documentos fiscais são emitidos em fluxo externo quando necessários.
